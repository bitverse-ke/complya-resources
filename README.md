# Complya Resources

Free practical resources for Kenyan data controllers and processors.

**Live site:** https://bitverse-ke.github.io/complya-resources/

## Contents

| File | Purpose |
|------|---------|
| `index.html` | Landing page — hero + cards linking to the two resources |
| `checklist.html` | The ODPC Registration Checklist as web-readable HTML |
| `checklist.pdf` | Same checklist, print/download-ready (1.3 MB, 18 pages) |
| `posts.html` | 10 ready-to-publish LinkedIn posts on the Data Protection Act 2019 |
| `posts.md` | Same posts as plain Markdown |
| `fonts/` | Inter + Playfair Display (TTF) — embedded for offline use |
| `photos/` | Nairobi-sourced background images |
